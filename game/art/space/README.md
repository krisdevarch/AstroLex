# Space stickers

Planets, the sun, asteroids, a meteor, a rocket, UFOs, a satellite and a spaceship that drift through
the play field behind the letters (`game/scenes/sky_drifters.gd`).

Source: a sticker sheet (`docs/design/space-stickers-sheet.jpg`) the owner supplied in the project thread on 13 Oct 2026 and asked to use in
the game. Each object was cut out on transparency by flood-filling the white background, then saved
at its native size (up to 256 px). Licence: the owner generated the sheet with an image tool and cleared it
for use in the game (13 Oct 2026, project thread). The tool's terms for commercial release are the owner's to keep on file.
